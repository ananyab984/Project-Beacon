# Comprehensive Multi-Stage Profile Enrichment & LLM Fallback Report

## Executive Overview

This document presents a comprehensive data transformation report for five public directory and professional profile platforms (**Ada**, **ATA**, **ATAA**, **Bodalgo**, and **LinkedIn**). The enrichment pipeline operates across four progressive stages:

1. **Stage 1: Raw Input Datasets** — Baseline input Excel/CSV datasets containing Profile Links and Case IDs.
2. **Stage 2: Raw Web Scraping / Extraction API** — Raw unstructured page content retrieved via **Tavily Extract API** (for directory sites) and **Bright Data API** (for LinkedIn).
3. **Stage 3: Formatted Output (Deterministic Parsing)** — Schema-aligned JSON (`projectbeacon_output.json`) generated by rule-based regex/string parsing into `Template_ProjectBeacon.xlsx` fields.
4. **Stage 4: LLM Enriched Output (Groq LLaMA 3.3)** — Final AI-enriched dataset (`llm_enriched.json`) filling remaining `null` slots.

## 1. LINKEDIN POC: BRIGHT DATA + GROQ LLM FALLBACK PIPELINE

### 1.1 Overview & Architecture
The LinkedIn POC relies on **Bright Data Scraping API** to retrieve raw profile JSON objects (including headline, about summary, experience array, education array, and skills). A deterministic parser maps these into `Template_ProjectBeacon.xlsx`, after which **Groq LLaMA 3.3** (`llama-3.3-70b-versatile`) performs strict extraction for explicitly stated years of experience, contact details, and organization affiliations.
